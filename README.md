# Uber-like App

## Project Documentation

### Introduction
This project aims to create an Uber-like application that connects riders with drivers.

### Features
- User registration and authentication
- Driver and rider profiles
- Ride matching and tracking
- Payment integration
- Ratings and reviews

### Technologies Used
- Node.js
- Express.js
- MongoDB
- React Native

### Installation
1. Clone the repository: `git clone https://github.com/kiplagatkatam/Uber-likeApp.git`
2. Navigate to the project directory: `cd Uber-likeApp`
3. Install dependencies: `npm install`

### Running the Application
- For the backend: `npm start`
- For the frontend: `npm start` (in the frontend directory)
